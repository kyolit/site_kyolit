KYÖL Informatique - version responsive

Modifications de cette version :
- menu de navigation cliquable sur tablette et smartphone ;
- blocs des zones affichés en 2 colonnes compactes sur tablette et smartphone ;
- bouton Facebook ajouté à la page Contact ;
- formulaire envoyé directement à contact@kyol.nc via FormSubmit, sans ouverture du logiciel de messagerie.

IMPORTANT - activation du formulaire :
Lors du tout premier envoi, FormSubmit transmet un e-mail d'activation à contact@kyol.nc. Il faut cliquer une seule fois sur le lien d'activation reçu. Après cette validation, les demandes sont envoyées directement depuis le formulaire du site.

Le site reste statique : aucune configuration serveur n'est nécessaire pour l'affichage. Une connexion Internet est nécessaire pour l'envoi du formulaire.
